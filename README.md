# Doga Erunver - code portfolio

This repository contains isolated code samples from my game development projects. They have been cleaned so they can be understood more easily.


While most of the code here is written in Godot's GDScript language (which is an object oriented language nearly identical to Phyton) due to it being the engine I make my games in (and to provide you with a clear look into how I handle algorithms and architecture).


I am very familiar with C# and know how to translate my knowledge into a C# environment.
As proof, I have also adapted some of my Godot scripts into C# scripts. You can find these code examples in the C#-Examples folder.
