# Doga Erunver - code portfolio
Code snippets organized here to act as a coding portfolio
This repository contains isolated code samples from my game development projects. They have been cleaned so they can be understood more easily.

All my completed games are built in Godot using GDScript. While GDScript is incredibly similar to the Python language, many practices and most of the architecture translates to C# and C++

*Important: Godot's engine calls (eg. `@onready` or `$Sprite2D`) have not been removed to provide context for how the scripts interact with the engine, but the logic itself can be carried over across different game engines.*
